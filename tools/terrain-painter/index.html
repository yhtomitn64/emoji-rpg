Wilderness Terrain Painter

❓ Help — what everything does (click to expand)

Loads all 25 wilderness screens onto one continuous canvas, laid out exactly like the real 5x5 world, so terrain painted across a screen boundary is connected by construction. The "Map" dropdown switches to the dragon dungeon or a mini-dungeon variant instead — each is a standalone map with its own palette, painted the same way. Pick a brush, click or click-drag to paint. Export copies a map's LEGEND/ROWS to the clipboard, ready to paste over its existing declaration in its file (wilderness screens live under js/maps/wilderness/; the dungeon and mini-dungeons live under js/maps/). "Place Dungeon Entrance" marks the one fixed spot every save's dungeon spawns at (only meaningful on the wilderness map) — "Copy position" copies the exact value to paste into DEFAULT_DUNGEON_ENTRANCE_POSITION in js/state.js. "Check Map" flood-fills from the town entrance in stages, matching the intended axe → pick → canoe (boat) → dragon progression: it only unlocks thicket/mountain/water terrain after confirming that stage's own tool dungeon is actually reachable with whatever's already unlocked, so a chicken-and-egg gate (like the pick dungeon sitting behind thicket while the axe dungeon itself is unreachable) gets caught. Yellow tint = only reachable with some tool, red = not reachable even with every tool, magenta = exactly where the first broken stage gets stuck. Dungeon-interior maps don't have their own reachability check yet. "Place Tool Dungeon Entrance" works the same way for whichever tool dungeon is selected in the dropdown next to it — copies paste into that entry's screenId/x/y in js/data/toolDungeons.js. "Choose Repo Folder" + "Export All Changed to Files" write every changed wilderness screen (plus the dungeon and tool dungeon entrance positions) straight to disk in one click, instead of copy/pasting each screen by hand — needs Chrome or Edge.

No folder chosen — writes straight to disk once you pick your repo's root folder.
